## 冻结与版本口径

- **研究阶段：** 最后阶段为 V1.7.5；本次用 `v1-final` 标识整个 V1 的收尾快照。
- **Python 包：** 标签中的已提交版本仍是 `0.6.7`，不因研究阶段收尾而虚改 API 版本。
- **工作区草稿：** 收尾时存在未提交的 `0.7.0` 版本字段、`docs/v180/`、
  `examples/agent_development/`、`agent_client.py`、`agent_service.py`、`agent_eval.py`
  及对应测试；它们保留原样，未作为 V1 完成交付纳入标签。
- **模型和实验数据：** 继续保留在本地 `outputs/` 等目录，未打包进 Git 标签。
  仅克隆 Git 可得到已提交源码和文档，不等于获得全部模型与逐调用记录。
- **私有服务资料：** API 地址、认证、私有接线脚本和费用附录不进入 Git。

因此，收尾标签固定的是**已提交的源码与证据说明**。未提交草稿没有被这个标签备份，
迁移工作区时需另行保存；模型、日志等大型产物的搬移遵循原交付说明。

## 保留的限制

1. Five Tribes 的两类规则边界未解决；Jaipur 极端平局及其他游戏已披露裁定继续保留。
2. Toy Battle 为关闭特殊基地效果的官方入门配置；Dominion 仅 First Game；其他游戏
   也只覆盖已选定配置，不声称涵盖基础盒所有模式或扩展。
3. 原版策略的分数和强度不能直接转用到变体。部分搜索标定未完成或未拉开差距，仍记为未知。
4. 三组工具直接对局存在不同的完成分布，Claude 受限额识别问题影响；不能用总体胜率做公平模型排名。
5. token 是已返回记录，CPU 是主进程计量；缺失 usage、CLI 子进程和外部推理不能据现有记录补齐。
6. Harmonies 当前河流计分采用图直径语义，扩展地形目标前应按规则和手工棋盘核对。

这些限制不因阶段收尾而删除，也不触发新的补测或训练。历史停止的队列保持停止。

## 进入 V2

V2 的主问题转为：**给定公开的新规则、受控 GT 交互和计算资源，agent 能否开发、
训练并迭代出有效策略，以及消耗多少资源。**

参见 [V2 起点与范围](v2/README.md)。第一批变体、资源额度和正式评测规模尚未落地；
本次完成阶段冻结和交接，不宣称 V2 环境或 benchmark 已完成。
