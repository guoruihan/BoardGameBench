# V135：把 agent 的布局判断接到 RL 动作上

## 问题与边界

V134 完成：reactive 两个种子在新的512确认局上平均111.08，对照110.45；
但开发局上的移除计划干预没有造成掉分，因此还不能说模型有效利用了计划。
V135 不仅继续添加特征，而是把公开布局目标编译成可解释的逐动作建议，
再让 PPO 学习什么时候采纳。这里的 agent 是编写策略规则的 coding agent，
**不是游戏中调用在线 LLM**，不使用付费 API。

继承固定的 V134 `reactive_a/final.pt`（预指定 A 副本，不按本轮确认集选择）。
保留 actor、critic、旧计划 adapter 及其 Adam 状态，继续整局自然终局 PPO；
奖励仍为真实分数增量/150，gamma=1，GAE=.95。没有搜索、伪奖励或新增隐藏信息。

## 判断如何进入动作

公开动物蓝图包含目标卡、锚点、所需地形堆叠和缺少的资源。
规则为240个动作产生[-1,1]建议：

- 拿能补足需求的资源组、拿目标动物卡；
- 在目标位置添加正确的下一层，避免破坏已规划的支持地形；
- 在正确锚点放目标动物，避免过早锁死尚未完成的支持格；
- 结束回合时不要丢弃目标市场卡。

不改合法动作掩码；所有合法动作仍可选。建议作为 logit residual，
固定强度0.6或可学习的0–2强度。保留原模型表达与拒绝建议的能力。
蓝图仍仅表达一/两个兼容动物布局，尚未解决多回合改建的全局规划。

## 自动实验

|方法|建议|更新目标|
|---|---|---|
|control|无逐动作建议；仍保留父模型计划特征|每原子动作刷新|
|advice|固定强度0.6|每原子动作刷新|
|gated|状态/目标条件下学习采纳强度|每原子动作刷新|
|sticky|学习采纳强度|最多坚持两个回合，失效/完成则重选|

每方法两个训练种子，环境池相同；stage1每任务新增4M动作。
由独立开发 audit512 的固定终点均分选一个建议方法，
与 control 两个副本一起继续各8M动作。即使候选暂时落后，也允许继续，
但不把“被晋级”解释为已证明有效。512曲线局、512晋级局、512最终确认局独立，
本轮新环境种子范围[50M,60M)。原训练池和正式测试集不变。

最终确认固定终点，对照父模型与持续训练 control。只在开发 audit 上做
移除/打乱建议诊断；这种分布外干预需要结合完整对照解释。
记录终局分数、动物分、完成卡、目标达成、行为概率一致性、gate 梯度和吞吐。
两个训练种子的环境配对区间不能代表跨训练种子的泛化不确定性。

## 资源与恢复

配置：`configs/v135_advice_a226.json`。
输出：`outputs/v135/advice_a226_20261021_a/`。
仅 a226 GPU0–3，stage1每卡两任务，57物理CPU核（上限64）；
stage2只用GPU0–1。预检使用8核，实际验证四张GPU计算和完整更新恢复。
stage1/2任务限时3600/4800秒，整个训练campaign硬保护3小时；
预检和检查另计资源。到界保存停止，不自动续期。

运行顺序（项目根目录；线程环境变量均设1，PYTHONPATH=src）：

```bash
.venv-train/bin/python -m boardbench.v135.campaign prepare \
  --repo "$PWD" --root "$PWD/outputs/v135/advice_a226_20261021_a" \
  --config configs/v135_advice_a226.json
.venv-train/bin/python -m boardbench.v135.preflight \
  --repo "$PWD" --root "$PWD/outputs/v135/advice_a226_20261021_a"
.venv-train/bin/python -m boardbench.v135.campaign launch \
  --repo "$PWD" --root "$PWD/outputs/v135/advice_a226_20261021_a"
```

本地回归通过后写入 `local_checks.json`，预检通过后才可 launch。
在命名 tmux 中通过 tee 留日志；launch 冻结源码。
恢复使用同一个 root 的 `resume`，只允许原截止时间以内恢复，不续预算。
阶段内 latest.pt 保存模型、gate、全部优化器、RNG和计数，要求源码/配置一致。
每批固定前4局保存动作/奖励/行为概率/计划，可按种子重建公开状态及建议；
不是挑最高分轨迹。代码和配置是归档的一部分。
