# V1.4.0 双人Harmonies环境与RL baseline

2026-10-22；包版本0.4.24。仍属于V1游戏环境与基线研究，不是V2自主编码平台。
设定为两人、相同A面、32基础动物牌、无自然精灵/扩展。旧单人任务完全保留。

## 官方规则与适用边界

来源：[Libellud规则书](https://cdn.svc.asmodee.net/production-libellud/uploads/2024/12/HARMONIES_Rules_EN.pdf)
与[官方FAQ](https://www.libellud.com/game/harmonies/)。
已核对规则书印刷页2–9、11及终局图示；本地文件SHA256
1e4ce6a9bf9c2e9d58ce8eee4fe6d80f6d3f439844b170a579ea78194786b5a7。
官方PDF不随源码重新分发。

- 共用120枚资源和32张牌；初始5组三枚资源、5张动物牌；双方各自23格棋盘。
- 回合中恰取一组资源，最多取一张牌，最多同时4张未完成牌；可以交错摆资源、拿牌、放动物。
- 回合结束只补缺少的资源组和动物牌。没有单人版的六资源弃置或任选弃牌。
- 自己回合结束空格<=2，或需要补资源而袋子已空，触发当前轮结束；必须双方回合数相等。
  抽出袋中最后三枚时仍能完成补充，不提前触发“补充时袋空”。
- 总分最高者获胜；同分比较已放动物数，再同则共同获胜（统计各0.5胜利份额）。
- 保留原地形/动物分、图案旋转、动物阻挡叠放及动物永久保留语义。
  动物块不作为有限消耗上限：官方FAQ允许用替代物补足。
- 双方盘面、已取牌、市场与剩余资源计数都公开；资源/牌的未来顺序和种子不作为模型输入。

环境API是HarmoniesDuo/FastHarmoniesDuo，观察包含players、active_player、first_player、
共享市场和双方得分；step.info明确acting_player。只在全局终局返回行动者的最终分差奖励。
这是双人API，不能直接塞入只支持单一总分的旧单人Runner/网页。

## 复用加速和迁移

- 原游戏地形/动物转换与评分复用；快速分支复用位集合合法性检查和结构化复制。
- 复用C++批量编码、共享内存多进程、GPU批量推理，保留参考编码和逐步等价测试。
- 动作为244个槽位；旧237–239弃牌槽禁用，新增4个槽表示额外资源组/牌。
- 两个重叠市场视图(0,1,2)/(3,4,0)完整覆盖5槽；再编码对手盘面，追加公共战略计划和8个对局字段。
  不是静默丢掉额外两槽，也不是把单人权重直接当成双人成绩。
- 从V138成熟FP64技能初始化；公共对手/额外市场残差头零初始化后学习。
  两座位各有独立的持久规划记忆，不能相互覆盖。

## 第一批实验

四个独立单GPU任务：自己总分PPO×两个种子、最终分差PPO×两个种子。
真实得分差分按“自己的下一次决策”计算；包含对手期间的得分变化，gamma=1望远镜求和。
对手动作从不混入自己的PPO损失；不添加动物分奖励或改变游戏分数。
对手池为50%冻结迁移策略、25%滞后快照、25%当前策略；快照未生成前后两者均用当前策略。

每10批在固定64个开发环境上交换双方座位（128局）验证，用平均分差选checkpoint；
结束后在未用于选型的512个确认环境上交换座位（1024局）确认。
训练种子[100M,200M)，开发[200M,300M)，确认[300M,400M)，旧正式测试集不动。
得分、动物分、分差、胜利份额及按环境聚类的标准误分开报告；自我对战50%不是强度证据。

本轮上限4小时，包含真实CUDA预检、训练、开发与确认评测、保存和清理。
a226仅GPU0–3；每任务13环境worker+1learner，总物理CPU并集57（含控制器），不超过一半。
源码冻结、资源锁、绝对截止时间、失败日志、最新/最好/最终checkpoint均保留。
正式运行前必须通过四卡真实成熟模型的梯度、行为概率、精确下一更新恢复检查。
没有通过预检则不启动正式训练，也不声称训练结果。

所有实际自对局动作保存为gzip，含环境种子、座位、行为logp、真实回报和源码/行为checkpoint摘要。
replay模块能重建公开状态、mask、动作与后继并检查终局；没有伪造搜索轨迹或额外专家标签。

## 运行

单场新环境演示（独立模型推理，无搜索）：

~~~bash
PYTHONPATH=src OMP_NUM_THREADS=1 .venv-train/bin/python -m boardbench.v140.play \
  --solo-parent outputs/v138/solo_baseline/weights.pt --opponent mirror \
  --seed 140 --out outputs/v140/example_match.json
~~~

已有双人推理权重时，把solo-parent替换为weights指向best_policy.pt。
训练入口为boardbench.v140.campaign；配置configs/v140_a226_duo.json。
必须在获准的a226节点、tmux后台启动；本机不自动SSH或抢占他人资源。
status.json/各任务curve.jsonl是进度；confirmation.json/done.json才代表完成评测。
outputs中的权重与原始对局不随Git推送。

恢复单任务使用该run的冻结source/src作为PYTHONPATH，原config加--resume。
必须先确认原进程已退出、资源可用；读取原latest.pt恢复模型、优化器、对手池、RNG和累计时间。
已完成任务或原绝对预算已过期会拒绝继续，禁止无声重置预算。

本批结果用于建立第一个双人学习基线；尚不声称战胜人类、达到最优或匹配单人112分。
单人每回合弃六枚资源、双人共享选择，得分尺度本就不同。
