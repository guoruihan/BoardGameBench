## 从哪里继续，为什么这样改

V144.1同权重诊断显示：在共同到达第11回合的小面板中，课程与正式双人的15.07总分缺口
有14.73来自动物分。课程强制换牌与正式双人的市场机制不同，这不是动物能力必然能直接
迁移的证据，也不是单靠多训练若干小时就能补齐的保证。

本轮先保持**所有训练和评测都在正式双人环境**。暂不增加更容易拿高分的课程：
先拆开对手非平稳性、动物布局的过程反馈和优质自身经验复用三个因素。
不改变规则、结束条件、动作掩码、公开信息权限、网络结构或原始计分。

共同父模型为V144第二轮`score_credit/best_policy.pt`，旧第二轮开发128环境总分84.34、
动物13.51；不是独立确认，也不能与不同种子的第一轮84.34直接当成配对比较。
父模型SHA256：`9e04354342de2db419748ccdcf7ac0434813f6e559a635281c1829fa59d09aad`。
V142父模型仍只作为结构初始化与固定评测参考；正式学习从V144保留权重接续。
轮间继承权重但使用新的Adam/RNG/回放池，不称作优化器精确续训。

## 第一轮四个独立实验

| 名称 | 对手 | 学习变化 |
| --- | --- | --- |
| control | 当前策略自弈，双方都学习 | 纯自身总分PPO对照 |
| fixed | 冻结的V144共同父模型 | 固定对手，只有当前学习侧进入PPO，两座位轮换 |
| plan_credit | 同fixed | 增加公开动物布局势函数差分 |
| own_replay | 同fixed | 自身历史轨迹的正优势自模仿辅助更新 |

固定对手始终是同一个V144父模型，不随轮间胜者更新。所有臂相同初始化和首轮随机种子，
环境种子序列按批对齐，但不同策略轨迹/随机抽样流会分叉。
每批128场；自弈有256条可学习轨迹，fixed有128条。相同墙钟不等于相同训练动作数，
报告必须同时保留动作量、耗时和进程占用。gamma=1、GAE lambda=.95，正式选模只按自身总分。

### 布局过程信号不是额外动物得分

复用已有公开规划器的至多两个兼容目标，只对**已经持有**的动物卡计算
`Phi = sum(marginal_animal_score / (1 + missing_tokens))`；市场中尚未拿到的卡不算。
规划器只读公开盘面、已有牌与公开资源数量，估计仍可能乐观，并非最优价值函数。
初始无持有卡，所以Phi初始为0；终局显式设Phi为0。

每侧自己的连续决策间，原奖励是自身真实分数增量/150，训练奖励改成
`raw_reward + scale * (Phi_next - Phi_now) / 150`，scale初值1。
整条轨迹的过程项严格相消，**总训练回报仍等于真实自身终局总分/150**。
环境本身的奖励/得分未改；每条归档同时保存原始奖励、训练奖励、Phi和MC回报。
独立原引擎回放重建公开规划器并验证这些量。

这是参考[势函数奖励变换](https://people.eecs.berkeley.edu/~russell/papers/icml99-shaping.pdf)
的有限局实现。这里直接检验的是整局回报守恒；不声称有限样本PPO一定提升或达到最优。
Phi来自有记忆的原规划器，不能把它解释为只依赖棋盘的精确状态价值。

### 自身经验回放与PPO分开

复用V133的有界FIFO Replay：保留最近4批所有学习侧决策，而非事后只挑高分局。
保存状态、合法掩码、动作、行为概率和完整MC回报；每个磁盘块带种子和摘要，训练种子外
的数据禁止进入。全部原始轨迹仍另行永久保留，FIFO限制的是在线回放池。

在当批正常PPO更新之后另做4个512样本的辅助更新：只让实际回报高于当前估计的动作获得
正优势模仿权重，并做相应正残差价值回归，系数0.05。旧数据**不进入PPO概率比**。
这是[Self-Imitation Learning](https://proceedings.mlr.press/v80/oh18b.html)的本地轻量变体，
不是对该论文整套采样/优化配置的复现。若后续组合势函数，回放目标使用对应训练回报，
不能拿原始回报与已塑形的critic直接混算。回放元数据/RNG随检查点保存，恢复校验不可变数据块。

## 后续迭代如何自行决定

三轮共享总预算，最后预留40分钟做统一开发选模和确认。

- 第二轮保留纯PPO对照及开发最高分策略；在胜者上补一个缺失的过程信号/回放机制，
  并测试50%当前/50%固定对手的分布变化。若继续臂和对照完全重复，改为独立训练种子副本。
- 第三轮保留对照和胜者，测试lambda1/.95切换。若总分配对区间为正且动物分增加，
  测较小学习率/熵；若势函数未改善动物分，做去掉势函数的消融；否则增加探索。
- 每轮决定、依据、父权重摘要在启动前写入`decisions/round_*.json`。保留旧最好策略，
  不是用最新权重覆盖。健康任务不因同批任务首次失败被停止；失败在原槽有界重试。
- 若重试后仍有失败，至少保留对照及另一个完成臂才允许下一轮，明确标注缺失，
  不给失败方法填0分。整个计划无法完成时保存失败记录，不自动扩预算。

这是已实现的、结果驱动的后台决策流程，不是后台无限LLM调用或无限自动改代码。
后续人工/agent分析可从保存的原始记录继续，不需要用户逐轮指定参数。
