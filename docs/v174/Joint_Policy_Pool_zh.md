# V1.7.4：冻结联合对手池与强度／风格标定

本版本将已有启发式、学习策略和终局搜索整理成可搬移、可核验的对手池。它用于下一阶段 agent 开发能力测试的准备，不训练新模型，不改变规则、计分或信息权限。[已有结果与交付](Results_zh.md)列出实际完成范围；本轮已停止，不自动补测。

## 覆盖与策略身份

覆盖 V1.6.0 已纳入评测的 16 个固定原版双人配置，继承其规则覆盖说明；Five Tribes 保持研究态，不纳入正式对手池。Jaipur 的可到达规则未决和 New World 的循环／截断边界仍需报告，不能将它们伪装成终局输赢。

共冻结 **101 个策略配置**：

| 配置 | 数量 | 内容 |
|---|---:|---|
| `heuristic` | 16 | 固定领域启发式 |
| `progress` | 16 | 已有长期进展启发式；Harmonies 使用 habitat |
| `legacy` | 16 | V1.7.2 保留的快速学习策略，作为该游戏固定锚点 |
| `candidate` | 4 | V1.7.3 的 Spice Road、Clever、Patchwork 正向候选及 Toy Battle 互补候选 |
| `search_30/180/900` | 48 | V1.7.2 已保留搜索配置，在三个累计决策预算下运行 |
| `search_score_900` | 1 | Harmonies 自身分数目标、habitat 续局的保留搜索 |

配置名称不表示强度顺序。搜索包含冻结学习策略的根动作建议／部分续玩，并非完全独立的纯启发式。`progress` 和 `candidate` 也是待标定成员，不预设优于锚点。

每个身份包含游戏、规则版本、配置、模型字节哈希、先验依赖、搜索目标／宽度／续玩策略／预算及随机种子派生规则。模型按内容复制，不使用指向训练目录的软链接。Guided 模型原始权重保持不变；嵌入的旧模型依赖通过清单显式改为池内路径。源码另存完整归档和逐文件哈希。比赛运行快照与最终发布的 CLI／报告代码可能不同；实际比赛以池内源码归档为准，报告分析另存代码身份。

所有外部可见输入仍是当前玩家的合法可见观察与合法动作，包括规则允许看到的自己手牌。终局搜索只能在可信评测进程中经现有 public-belief bridge 使用环境；不可把裁判快照、真实隐藏牌序或随机数状态交给被测 agent。

## 本轮标定协议

原计划固定 11,872 局，使用新的标定环境种子 174010000 起，起始玩家固定席位 0，并交换策略席位。这个规模超出了用户“一轮并行检查”的意图，尤其是 608 场 900 秒对局超过同时运行容量、形成多个批次。收到纠正后已停止全部本轮评测队列，取消尚未启动的追加面板。以下保留原计划用于审计，不表示已经完成或将继续运行。相同初始种子不保证不同动作之后仍抽到相同未来随机事件。正式 test 不参与本轮。

- 快速策略全互战：每对 64 个环境 × 两座位。
- `legacy` 自对弈：64 个环境，提供分项风格比较的共同参照。重复的席位排列不增加独立环境数。
- 30 秒搜索对 `legacy`：32 个环境 × 两座位。
- 180／900 秒搜索对 `legacy`：各 16 个环境 × 两座位。
- Harmonies 分数搜索对 `legacy`：16 个环境 × 两座位。
- 四个新候选对 900 秒搜索：各 8 个环境 × 两座位，作为描述性补充，不单独据此强度晋级。

搜索预算是**单核、每局累计决策时间**，不是每步时间。保留每局模拟步数、完整候选轮数、实际决策时间及耗时最大的动作。计时搜索受到硬件与负载影响：冻结代码和种子保证配置可恢复，并不承诺逐动作位级重现。长预算匹配另有搜索预算之和加 180 秒的外部墙钟上限；快速局最多 180 秒，两者均最多 10,000 次原子决策。超限或规则未决保留原状态，不补写终局奖励。

已有 V1.6.0／V1.7.2／V1.7.3 结果作为候选来源与历史依据保留。本次新分档只使用统一的新标定面板，不把不同对手、规则／保护包装、预算或种子协议的历史成绩直接拼入样本量。

## 强度与风格分别报告

强度以该游戏 `legacy` 为锚点，不假设所有对手存在可传递的总排名：

- **锚点以上**：完整面板、至少 16 个独立环境、胜率至少 60%，且名义区间下界高于 50%。
- **锚点以下**：同样完整且至少 16 个环境、胜率至多 40%，且区间上界低于 50%。
- **未决**：其余已完成比较。未拉开差距不等于证明等强。
- **证据不足**：面板未完成、出现未知结果或独立环境不足。

当锚点两侧都存在成员时，可以形成相对低／中／高三个层次；否则明确保留两层或未定层次，不人为填满三档。完整对战矩阵保留，未测搜索之间的对阵标为未知。

胜率将平局计半分。统计先按环境聚合两个座位，再做 bootstrap；同时与按独立环境数计算的 Wilson 区间取包络，避免小样本全胜产生零宽区间。这是探索性名义区间，未做多重比较校正，也不声称严格覆盖保证。未知结局另给全计划胜率上下界，不能把完成局均值冒充全部计划成绩。

风格描述取**相同 legacy 对手和共同初始环境**下的动物／地形、经济／计分等终局分项及动作类型比例，再与锚点自对弈比较。差异按环境聚合，至少 16 个共同完整环境才产生分项差异标签。差异标签是未校正的描述统计，不意味着因果偏好；更低动物分也可能只是能力不足。原始分数只在同游戏、同对手条件下比较，竞速和直接占领获胜游戏以真实胜负为准。

## 预算、恢复与后续边界

本轮原来自设上限为 200 worker 核时、启动后两小时，但已按用户纠正提前停止，剩余额度不续用。使用远端 CPU，每台最多半数物理核心。worker 核时按单核子进程墙钟累计，包含加载／进程启动／I/O，是保守资源口径；另报告实际比赛 CPU 时间，两者不能相加。协调进程及开发验证开销单独说明。不使用 GPU。

每个结果有配置、策略和内容哈希，队列恢复不会覆盖完成结果，也不会自动延长原截止时间。本轮只允许重新汇总现有文件，不恢复比赛队列。未运行和中断项保留为未知，不删除失败项来凑完整面板。所有机器地址、tmux 启动脚本留在忽略目录。

这一步不启动其他 agent 的开发实验。后续仍需固定开发接口、交互和算力额度、推理限制，以及与此标定集隔离的测试种子／对手划分。

发现自身搜索时间超限的配置会标为 `budget_violation`，即使终局获胜，也不会进入上下档或推荐风格角色。超限只归因于实际超限的搜索席位，不把其对手一并认定为超限。证据不足直接标注；不因区间跨过 50%、档位未填满或面板被停止而自动追加比赛。后续如需要新评测，应先明确总场次和并行波次数，不能只用“每局 900 秒”代替总成本说明。
