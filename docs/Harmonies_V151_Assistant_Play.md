## 具体观察

1. **动物组合执行是本次表现较好的部分。** 双人每局动物分都高于同局 RL 对手，平均
   多 17.375 分；平均放置 8 个动物，对手 4.5 个。多次复用地形完成一张卡，再选择可兼容
   的卡片。duo4 以青蛙和水獭复用绿色支撑，并保留长河道，最终 93:69。
2. **空间和地形收益抵消了动物优势。** 双人平均地形少 18.625 分。单人全部在 9–11 回合
   结束，常因空地不足失去后续收益；duo3 只玩到第 8 回合，动物 28 分仍以 61:66 落败。
   追逐动物图案时低树过多、堆叠不足、河道不连贯，是值得从这些轨迹检查的具体问题。
3. **局部计分判断会出错。** duo1 最后一回合开始时已是 96:95。我把灰色9改成建筑，
   建筑得到 5 分，却使相邻的高山失去唯一山邻居；两格合计丢掉 8 分，总分降到 93，
   变成 93:95 落败。动作合法，结果完整保留。
4. **非法请求也保留。** solo3 一次动物放置在支撑高树完成前被拒绝。此前同批已合法执行
   的资源放置保留，之后从真实状态继续。这是全体 16 局唯一被记录的失败提交。

这些观察支持“助手能给出有用的动物布局演示”，尚不足以证明能稳定胜过 RL。
本次没有训练新模型，也没有将这些演示自动并入训练集。

## 实际方法和比较边界

- 环境直接复用 `Harmonies` / `HarmoniesDuo`，使用现有 A 面、基础 32 张动物卡、原始计分
  和终局条件。单人及双人的供给、市场和结束规则各自保持原定义。
- 我方为当前会话 Codex 的交互式决策。工具提供格子编号、公开市场、双方公开棋盘、
  分数拆分以及当前已经匹配的动物锚点；锚点位置仍由助手选择。相同位置存在等价合法
  朝向时，接口仅选择对应的合法几何见证。没有调用搜索器或其他策略替我方选择动作。
- CLI 输出来自公开 observation。可恢复文件还含私有袋子/牌堆快照，未作为我方决策输入；
  不应把这些快照当作后续学习模型的观察。规则和几何资料查阅不提供隐藏未来。
- 对手是 `configs/harmonies_duo_play.json` 当时配置的网页 RL 模型 **V147 r2_continue**，
  使用既有 `SelfplaySolver` 的公开特征、布局提示和确定性 argmax 推理，全程冻结。
  这轮没有使用搜索对手，也没有自动替换网页默认模型。
- 16 个种子和座位在开始前写入 manifest。对局按小组推进，助手会从早期失误中调整后续
  玩法，所以这不是固定策略的 16 次独立采样。8 局单人的前 4 局均分 81.75，后 4 局 95.50；
  这也可能受种子差异影响，不能单凭前后均分证明学习效果。
- 没有给助手设置与 RL/搜索相同的决策时限。不能把这里的单人 88.625、双人 84.75
  直接与历史不同种子、不同对手、不同预算的均分排名。单人/双人本轮 seed 也不配对。
- 从 session 初始化到最后终局约 **93.08 分钟**，包含对话推理、工具往返和等待，
  不是 CPU 核时或纯推理基准。对手在本机 CPU 单线程推理；本次没有 GPU 或新训练任务。

## 证据、重放和恢复

已验证全部 **1,486 个合法原子动作**，其中我方 **1,013 个**、RL 对手 **473 个**。
从固定 seed 重置后，逐步检查公开观察及其哈希、行动者、合法性和最终完整状态；
另从新建的对手状态重新推理，473 个 RL 动作全部与原记录一致。
5 个专项测试覆盖恢复、权限、批次跨回合拒绝、合法前缀保存、审计篡改检测和胜负汇总。

运行产物保存在项目本地，按仓库约定不提交 Git：


```bash
.venv-train/bin/python -m boardbench.v151.play \
  --root outputs/v151/assistant_play_20261026_a --view solo5 duo4 duo7
```

接口代码在 `src/boardbench/v151/play.py`。`--init` 只初始化一个**新目录**的固定 16 局，
不会自动替助手下棋，且拒绝覆盖已有 manifest。未结束的局面可用 `--view` 读取当前 `rev`，
再通过 `--requests` 提交 JSON 数组，例如：

```json
[{"game":"solo0","rev":0,"commands":["b0"],"note":"选择公开市场的第一个资源组"}]
```

上例仅展示请求格式，不适用于这批已经结束的游戏。每次提交必须带当前 revision 和简短
动作意图。`bN` 拿资源组，`cN` 拿动物卡，`m/u/w/g/y/r` 分别表示灰/蓝/棕/绿/黄/红，
加格子编号放资源，
`a卡号@格号` 放动物，`e` 结束回合，单人的 `dN` 结束回合并丢弃指定市场卡。
结束回合只能是批次最后一步。若批次中后续动作非法，已执行的合法前缀会保存，不回滚。

**可精确复现的是已记录轨迹及冻结对手的行为。** 会话助手未来再次思考同一局面，
不保证给出相同动作；本版本未包装一个可无人值守重复调用的 LLM 策略服务。
