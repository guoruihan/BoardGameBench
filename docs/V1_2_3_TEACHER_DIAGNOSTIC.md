# V1.2.3：候选剪枝与后续策略诊断

本版本先回答“好动作是否被剪掉、模拟中的后续玩家是否限制了评估”，不增加到256×，不开始新RL/模仿训练，不自动更换部署策略。V1.2.2继续按原计划运行，终局16×保留为当前高预算参考。

## 冻结的问题与对照

当前代码使用原启发式 **top6**，不是旧文档中的top4；终局模拟也一直使用该启发式。更精确地估计这个策略的后续价值，不等于最优规划。

| 后续策略 | 与前一对照的差别 |
|---|---|
| original | 完全保留现有启发式排序和稳定平分规则 |
| space | 加入公开剩余补给对应的空格成本、已有格堆叠机会、动物锚点封锁成本 |
| habitat | 在space上加入资源可达图案、逐步完成奖励、不可逆破坏代价和布局冲突处理 |

habitat枚举每张活跃卡的可达图案，检查堆叠前缀、动物封锁、所有需求格的颜色资源总量；贪心选择每卡最多一次完成的兼容目标，允许共享相同支持地形，禁止共享动物锚点。拿牌和选资源也考虑这些目标。它仍是有限启发式，不是完整回合或多卡顺序最优规划；不兼容的同时目标不代表合法的先后组合不可行。

资源可达性是**公开数量的乐观上界**：选择资源前包含全部市场资源（实际上只能选一组），选择后不包含其余不可拿的资源；未来供应数量已知，但取得这些颜色的时机与组合未知。所有额外项只用于动作排序，rollout最终只用原始真实总分。

## 两阶段实验，禁止从复核结果重新选动作

1. **发现：**每个状态按原启发式顺序枚举全部合法动作，在三个固定后续策略下各模拟8个随机未来到自然终局。同一状态内各动作/策略共用样本种子。
2. 对每个后续策略，按发现均值冻结三个选择：前6最佳、被剪动作最佳（若存在）、全动作最佳。平分保持原排名。把选择和发现值写入`selection.json`。
3. **独立复核：**三个策略的上述动作并集（最多6个不同根动作），每个根动作在每个后续策略下再模拟64个新的随机未来。确认随机流与发现流分离，且不同后续策略面对相同根集合。
4. 复核结果即使为负也原样保留，不重新挑复核最高的动作，也不按每个已见随机未来挑“最聪明的后续策略”。这不是完美信息搜索。

这里8次发现/64次复核用于受控局部诊断，**不是直接复现终局16×的整局行动分布**。发现阶段仍可能漏选好动作；没有发现剪枝损失也不能证明top6充分。

主要对比：

- `all_minus_top6`：发现阶段从全动作选出的动作，独立复核是否胜过前6赢家。
- `outside_minus_top6`：被剪动作中发现赢家的独立差值；只有存在被剪动作的状态才适用。
- `fixed_root`：固定original发现选中的前6赢家，只换后续策略，分离空间和动物规划的后续收益。
- `root_switch_under_new/original`及`preference_interaction`：分别用新/旧后续策略复核新旧根动作，检查动作偏好是否变化；不能把所有动作一起涨分误当成排序改善。

主报告仅使用所有状态/策略/样本完整的预定环境前缀8/16/32；源环境内先平均局面，再计算环境间均差和描述性正态95%区间。不是64个独立游戏，也不是把数千个rollout当独立环境；区间未校正多重比较，不做局面级显著性筛选。

每条rollout保留真实总分、地形/动物分、回合、已放资源、动物数、完成卡、空格数和模拟步数。任何安全步上限/异常都是失败，不能把部分分数冒充终局。总报告保留失败、截断和未开始状态；阶段不完整不进主结果。

## 决策规则与后续边界

- 独立复核显示剪枝损失：优先改候选覆盖/多样性，再测完整局实际耗时。
- 固定根或偏好随后续策略改善：保留空间/动物两个对照，继续检查后续玩家的具体轨迹。
- 都不明显或负结果：保留证据，不解释为游戏接近最优；再讨论回合宏动作、启发式缺陷或更多发现样本。
- 完整回合有限宽度搜索留到下一步；随机信息揭示后必须重规划，合法原子提交不能绕过。
- 任何后续高分主张都需完整局、相同实际预算和新确认环境；每局3秒部署仍单独评估。本次不训练、不发布新线上策略。
