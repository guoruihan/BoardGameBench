## 内部计分信号

在 512 局直接对照中，Spice Road 的订单分为 62.76 / 61.66，剩余香料分为 1.66 / 1.12；Clever 的绿色区域为 30.36 / 22.94，狐狸奖励为 23.19 / 20.17，同时黄色、橙色区域有所下降。Patchwork 的纽扣分为 37.52 / 34.21，空格为 10.23 / 10.35。以上均为候选 / 旧 RL，描述实际分数构成，不单凭分项推断因果。

Harmonies 在大确认中双方动物分均为 13.09；对独立 900 秒搜索的 8 局中，候选动物分为 13.00，搜索为 30.62。本轮没有填平动物组合能力的差距。

Toy Battle 的 512 局中，384 局以勋章目标结束，候选赢 56.25%；71 局以攻占总部结束，候选赢 25 局（35.21%）；57 局因当前玩家无法抽取或放置结束，候选赢 42.11%。这是按终局原因划分的描述统计，分组由双方玩法共同产生；它提示需要检查终局路线与防守，而不能将勋章增长直接视为更强策略。

## 实际做了哪些迭代

| 方向 | 内容与观察 |
|---|---|
| 完整公开输入与搜索初始化 | 新上下文 actor-critic 读取完整局面/动作树及候选特征，旧 RL 提供冻结先验。比较胜负与胜负/分差目标，保留计分分项辅助头。 |
| 监督方式与较长模仿 | 尝试硬标签、选择性保留旧策略、更长 BC、Monte Carlo 回报。Clever 的最终有效候选是 iter2_mc/bc_final。长 BC 并非普遍有效：Toy 的训练动作准确率曾达 97.24%，Splendor 达 84.49%，实际开发对局仍退化。 |
| 学生局面补数与保守修正 | 加入学生实际经过局面的教师标签，再收集 0.5 概率执行教师动作的混合轨迹；保留实际执行动作及真实终局回报。另测试 actor 修正缩放到 0.25/0.5。未观察到普遍稳定提升。 |
| 探索与在线更新 | 同模型贪心/随机探针显示明显差距，加入温度一致的 PPO，分开 BC/PPO 学习率。Patchwork 的最终正向候选来自修复后的低温 PPO；Spice Road 来自 iter2 PPO。 |
| 价值目标与纯 PPO 对照 | 测试仅回放专家动作、在线 critic 只拟合自己的回报，并在 Clever 测试关闭示范回放和旧先验 KL。后续快照仍波动，没有可靠超过较早的模仿模型。 |

Harmonies 的旧策略适配器只提供选中动作，因此当前冻结先验是该动作偏好；其余通用旧模型可提供连续 logits。随机探索的分布并不等同于原模型原有分布，这是后续需要单独检查的接口差异。完整编码保证字段可见，不保证一个小型池化网络能高效学会空间组合。上述失败不能简单解释为“游戏已经接近上限”，也不能仅凭这些对照断定表示或价值目标是唯一原因。

## 数据、成本和验证

- 50 个实际进入模型阶段的训练/模仿分支，另有 16 个 actor 修正比例候选。48 个训练分支正常结束；两个低温分支因数值保护退出，其有效模型由新的恢复分支接续，原记录保留。
- 在线采样共 531,744 局，21,264,356 次学习者决策；其中 62 个未完成采样局不进入终局 PPO 标签。这里累计各分支实际交互，并非同等数量的不重复环境种子。
- 保存 871 个有效专家标注对局：72 个原有对局，加本轮 128 个高预算教师对局、32 个学生局面标注对局、511 个有效较低预算教师对局、128 个教师/学生混合对局。另有 1 个 New World 180 秒教师对局实际用了 181.51 秒，保留原记录、排除训练，并在教师质量检查中计作失败。
- 学习者及采样子进程已计量 CPU 下界 139.69 核时；教师/标签/搜索对照记录 99.32 核时；失败启动已观察到 0.63 核时，合计已计量下界约 **239.64 CPU 核时**。评估、编码、启动、探针和部分失败清理未被完整计量，实际全流水线 CPU 成本更高，不能把该下界当完整 benchmark 硬预算。
- GPU 按物理卡合并重叠任务，约 **36.46 A100 卡时**，峰值涉及 17 张卡；这是设备占用估计，不等于满负载计算时间。多任务共享卡已实测运行，该卡数并非所需最小资源。
- 每台自身分配最多半数物理核，最高 64/128；a 系同时遵守最多 128 核的旧上限。监控未发现采样子进程 affinity 越界，启动前检查整机占用及 GPU 外来进程，不覆盖他人任务。
- 65 项相关测试通过；真实 A100 更新、行为 log-prob 对齐、合法动作/终局标签、冻结词表跨源码目录一致性均检查。低温 KL 下溢在实际失败的 726 条样本上复现并修复，保留非有限损失保护。
- 首次选择性分支发生词表源码路径兼容问题；一次混合轨迹队列使用了错误源码目录，在任何结果纳入数据前停掉并重建。相关失败、源码快照和成本证据均保留。游戏规则、计分和可见信息权限没有修改。

本地根目录为 `outputs/v173/search_guided_rl_20261101/`。权重、轨迹、私有机器信息不进入 Git。

| `report/development_and_confirmation.png` / `.pdf` | 开发筛选曲线与独立确认点，明确区分两者 |

暂定选择是研究用途，不是八任务多重检验后的最终认证；所有旧策略仍可调用。8 项暂定策略的加载/首个合法动作检查通过，强度证据来自上面的完整确认。带 `initial` 名称的检查点可能继承已经训练过的父模型；例如 Clever 的冻结文件最终追溯到 `iter2_mc/bc_final.pt`，不能误称纯 PPO 新增收益。

```python
import json
from pathlib import Path
from boardbench.families.registry import game_class
from boardbench.families.play import make_policy
root = Path("outputs/v173/search_guided_rl_20261101")
pool = json.loads((root / "retained_candidates_v173.json").read_text())
game = "patchwork"
env = game_class(game)()
env.reset(seed=123, first_player=0)
bot = make_policy(game_class(game), pool["games"][game]["provisional_choice"])
action = bot.decide(env.observe(env.current_player), env.legal_actions())
env.step(action)
```

使用训练虚拟环境并设置 `PYTHONPATH=src`。窗口内中断恢复可用原源码快照和原配置运行 `boardbench.families.guided_training`；配置哈希、优化器和随机数状态会校验/恢复。原截止时间不会延长，本轮结束后该配置不会自动续训。重新开展实验需要新的输出目录与时间窗口。
