# Harmonies 阶段总结

收尾日期：2026-10-31。研究版本 **V1.5.1**，包版本 **0.4.39**，Git 标签 **v1.5.1**。

本阶段完成了一个可运行、可评测的 Harmonies 任务，并由 Codex 在用户给定的研究方向、
方法建议和资源约束下进行策略开发与实验迭代。用户确认方向并提供反馈，Codex 负责实现、
实验执行、结果分析和后续变种探索。代码、方法说明和结果记录构成此次收尾快照。

## 已交付的任务

- 单人和正式双人环境，包含棋盘、基础动物卡、合法操作、计分和自然终局条件。
- 明确的公开观察与私有恢复状态边界；双人共享市场、独立棋盘及双方回合管理。
- 环境加速、策略评测和训练代码，以及与已训练双人策略对弈的可视化界面。
- 可恢复的实验记录、固定种子与模型标识、逐局计分、轨迹保存和精确重放审计。

## 已完成的策略探索

从已有启发式和搜索策略出发，探索搜索预算、终局 rollout、候选动作、动物栖息地布局、
回合组合规划，以及利用专家轨迹进行模仿学习、PPO 和价值引导搜索。
不同策略及其结果保留在各阶段记录中；高动物分和高地形分之间的取舍仍是主要问题。

最近一轮 V150 完成 23 轮迭代和 69 次拟合。冻结后的主验证使用同一批 128 个新环境、
两座位，每种策略 256 局，共 1,280 局，均通过自然终局和重放检查：

| 策略 | 平均总分 | 动物分 | 地形分 |
| --- | ---: | ---: | ---: |
| 原纯 RL | 85.64 | 13.77 | 71.87 |
| 终局 rollout，1 秒/原子决策 | 87.05 | 23.60 | 63.45 |
| V149 价值搜索 | 82.37 | 24.06 | 58.31 |
| V150 保留方案 r17 | 81.61 | 27.63 | 53.98 |

V150 相对 V149 的动物分提升得到配对结果支持，但地形分损失抵消了收益，总分没有确认
改善。价值/排序模型仍与搜索配合，未替换原纯 RL 演员或网页默认对手。
这组搜索预算是每次原子决策 1 秒，不能与历史每局 900 秒的高预算成绩直接等同。

方法和详细证据：[V150 方法](Harmonies_V150_Eight_Hour.md)、
[V150 结果与限制](Harmonies_V150_Results.md)、[V149 结果](Harmonies_V149_Results.md)。

## Codex 直接作为玩家的补充测试

V151 由当前会话助手明确选择每个我方动作，使用模拟器提供的公开局面、计分和合法性工具。
完成预先固定的 8 局单人、8 局双人；双人对手为冻结的网页 RL 策略，双方先后手各 4 局。

| 模式 | 我的均分 | 最高分 | 结果 |
| --- | ---: | ---: | --- |
| 单人 8 局 | 88.625 | 101 | 最低 65 |
| 双人 8 局 | 84.750 | 93 | 3 胜 5 负，对手均分 86.00 |

双人动物分平均 34.50 对 17.125，地形分 50.25 对 68.875。动物组合执行较好，但空间利用、
堆叠和收官不足；包含一次最后回合操作导致总分下降并输掉的真实失误。
全部 1,486 个动作重放一致，473 个 RL 对手动作与重新推理一致。

这部分测试中 Codex 是玩家；前面的策略研发中，Codex 是组织和执行实验的研发助手。
两种角色分别记录。直接试玩属于持续交互的小样本测试，未统一思考时间，也未冻结助手
跨局调整玩法的过程，因此不用于宣称胜过历史搜索或固定 RL 策略。

[逐局结果、方法和重放入口](Harmonies_V151_Assistant_Play.md)。
