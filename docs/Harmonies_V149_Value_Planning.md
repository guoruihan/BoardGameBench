# V1.4.9: 每次决策限时的价值引导搜索

2026-10-26，包版本0.4.36。实现依据用户提供的
`tmp/harmonies_value_guided_rl_plan.md`，先做一个有明确边界的实验循环。

## 目标与复用

正式双人A面/base32，固定V144对手，优化自身原始总分。沿用精确引擎、
公开库存重采样、原子动作、合法mask、完整轨迹重放和V148价值训练器。
保留V147模型和900s/局终局rollout，不修改网页对手，不重启旧实验。

旧V148相同16环境双座位：终局rollout98.94，MCTS93.56，MCTS+价值90.00。
旧价值对留出实际回报RMSE约11.2分；降低MSE没有自动产生搜索收益。
这些是高预算开发结果，不能替代本轮0.1/1s每次调用的对照。

## 算法与信息权限

- 每次真实原子动作调用预算0.1或1秒；不是每回合、整局或训练预算。
- 六个混合候选来自固定模型、habitat和地形排序；各方法使用相同候选机制。
- `value_one`：执行一个候选；若轮到对手，按冻结对手模拟到己方再次行动，
  然后评价。无随机事件的直接后继只评一次，不重复同一个确定性预测。
- `value_short`：最多两个己方原子动作后截断；第二步使用habitat。
- `value_turn`：使用habitat完成当前回合，模拟冻结对手，到己方下个决策评价。
- `rollout`：在同一调用预算内用habitat/冻结对手模拟完整终局。
- 这是根候选搜索加固定后续策略；没有宣称联合优化完整宏动作或实现新的MCTS。
- 每轮给所有候选共享一个从公开库存重采样的未来；不读取真实私有牌序。
  仅完整的配对候选轮次进入均值，超时半轮不参与比较。
- 叶子使用当前己方分数+150×预测剩余己方分数。终局直接用真实分数，
  对手回合先模拟完，不切换价值视角，不用环境的终局分差reward。
- 复用完整FP64模型的价值权重，但跳过动作head、softmax与动作排序；
  新路径与完整forward做数值一致性检查。

## 计时边界

候选生成、模拟、编码、推理、IPC与选择均计入调用时间。Python内部时钟和
SIGALRM不能可靠中断正在执行的原生计算，因此评测采用常驻子进程。
父进程保留合法回退和已完成轮次的最佳动作，到期返回并SIGSTOP自己创建的
搜索子进程；下一次调用才恢复。父子共享同一个被固定的CPU，不后台偷跑。
旧请求和超时半包有序保留、按请求ID隔离；对局结束只清理自己的子进程。

这不是硬实时操作系统。记录每次实际耗时、超额、父进程超时、回退率和整局
累计时间。时序门槛容许最多2ms测量/调度误差，但所有正超额仍单独计数，
不隐藏原生调用或调度超时。未过门槛的方法不进入扩测选择。

## 数据与训练

从旧240局/15999状态的不可变数据中筛选176局`search_habitat`，核对原始行
与轨迹收据顺序，保留剩余真实得分/150标签。禁止开发/确认数据进入训练。
新模型的所有Linear权重重新初始化；两个学习率共享同一起点、同一环境分组
划分，避免直接拿旧已监督权重的拟合作为新的留出泛化证据。旧V148价值单独
保留为历史对照。初始两路各1800步，单卡依次训练，无DDP。

按环境分组留出约20%，同局两座位不跨划分。训练有完整优化器、RNG和权重恢复；
预检必须在实际设备验证非零梯度、下一步精确恢复和导出数值一致。

候选排序诊断在留出的训练来源局面上进行，覆盖早中晚阶段。对照归档的
habitat终局rollout候选Q，报告经验选错损失和超过采样噪声阈值的两两排序。
这些Q对应固定habitat后续策略，不是最优Q，也不是高预算搜索每步重规划的真值。
诊断只用于解释，不能单凭该指标宣布策略变强。

## 首批流程与资源

最新授权主机a227；a234只保留用户网页。最多24个单线程评测槽、1个训练槽、
1个控制槽，共26物理核，低于128物理核的一半。训练只用启动前确认为空闲的
GPU（当前选择GPU1），不碰其他GPU进程。CPU与GPU分配时间分别记录，离线训练不算作在线用时。

1. 筛选旧数据，实际GPU预检，两路独立价值训练。
2. 旧/新价值的候选排序诊断。
3. 同4个开发环境双座位：模型、habitat、匹配0.1/1s的终局rollout，
   旧/新价值的单步、两步和回合截断对照。
4. 每个预算选一个通过时序门槛的价值假设，进入新16环境双座位扩测。
   即使小面板没有赢，也扩大验证；不套用旧“必须接近900s教师”的停止条件。
5. 保留结果与模型，按真实总分、动物/地形分和时延决定下一轮是否补充分支状态。
   首批不自动替换正式baseline，不将开发选型结果冒充正式测试。

初次试验最多2小时，从启动计时，到期保存并停止；旧预算不续用。版本源码冻结
到运行目录，长任务由tmux运行，父守卫在截止时只清理本任务进程树。

## 启动与恢复

在a227项目根目录：

```bash
.venv-train/bin/python -u -m boardbench.v149.launch \
  --config configs/v149_value_planning.json \
  --root outputs/v149/value_a227_20261026_a --hours 2 --workers 24 --gpu 1
```

放在命名tmux会话中，并将输出通过`tee`写入项目日志。结果入口为运行目录的
`status.json`、`pilot_summary.json`、`expanded_summary.json`、`summary.json`。
单局有原始轨迹、实际延迟、独立参考引擎重放校验；训练曲线和模型位于`fit/`。

在原截止时间内恢复，使用冻结代码和原配置：

```bash
PYTHONPATH=outputs/v149/value_a227_20261026_a/source/src \
  .venv-train/bin/python -m boardbench.v149.launch \
  --root outputs/v149/value_a227_20261026_a --resume
```

完成或过期的窗口不允许续跑。正式新窗口需单独授权；生成数据、模型和运行目录不入Git。
