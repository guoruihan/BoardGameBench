# V1.2.2：先诊断搜索老师，再考虑学习压缩

## 问题与边界

本轮只回答 Harmonies 上两个问题：现有短搜索增加实际采样后能否提高；使用现有启发式模拟到终局是否更好。不更换 PPO、不训练模仿模型、不评测其他游戏、不使用 confirmation/test、不自动更新线上策略。曲线变平不是最优性证明。

历史 **85.203125** 来自 V1.1 完整对局搜索，平均约 **13.60 秒 solver work/局**；并非 V1.2 的 3 秒限时分。其选定参数见 `outputs/v11/harmonies/test/search_turn_384/shard_000/config.json`。本轮复用参数，不复用旧测试局，也不把新高预算结果当作同预算部署提升。

## 冻结方法

|方法|根候选|每候选采样|后续决策|结束/估值|
|---|---|---|---|---|
|heuristic|全部合法动作的原始启发式排序|无|原始启发式|真实对局自然结束|
|short|原始启发式 top6|4 × 倍率|同一启发式|2 回合或分支预算；原 potential leaf|
|terminal|相同 top6|4 × 倍率|同一启发式|自然终局真实总分；禁止用截断分替代|

- 倍率为 **1、4、16、64**。短搜索总模拟步上限同时设为 **384 × 倍率/决策**，保持同样的单分支预算分配；不会只增加一个已不起作用的上限。
- `BoardSolver` 算法不变。1× 参数精确为 width6、rollouts4、depth2turn、cap384、potential leaf。不同实际轨迹可能导致耗时和模拟步不严格成倍。
- 终局 rollout 每分支最多256个原子动作，仅作安全界限；超界直接记录失败，不伪装成完整 rollout。它的1×与短搜索1×不是相等实耗，必须看实际秒数/模拟步数。
- 两者在每个决策内对候选使用共同随机未来样本，均选择平均估值最大的候选，平分保持原排序。跨预算的随机数消费会因轨迹和采样数不同而变化，不能声称完全配对的未来流。
- 终局后续策略使用一个有界 LRU 公共观测→启发式动作缓存。缓存不存未来条件价值、不含实际隐藏顺序；缓存开/关及恢复后的动作和估值一致性有测试。
- 保留根剪枝覆盖率、rollout/自然终局/达到短搜索视野的比例、动物/地形分、缓存命中以及每次真实决策轨迹。后续若曲线平，再检查候选剪枝、动物规划、叶估值和后续策略，不在本轮见分调参。

## 信息边界

真实引擎只给 solver 当前公开观测。模拟器从 `Harmonies.from_observation(public, simulation_seed)` 重建公开剩余数量并随机采样未来，绝不读取真实对局的 bag/deck/RNG 或完整快照。模拟中的后续策略只看到每一步届时的公开观测，不看采样未来、模拟种子或环境种子。缓存键是完整公开观测的摘要。

## 资源与运行管理

注册配置：`configs/v122_harmonies_search_scaling_20261019.json`。本次绝对截止时间为 **2026-10-20 00:12:00 Asia/Shanghai**，即用户提出任务约八小时后；开发、校准和验证的墙钟时间也在这个窗口内。到点保留未完成格，不承诺128局矩阵一定全部完成。

- b35 共128个物理核；用户授权最多一半。本轮固定64个不同物理核：1核供控制器与独立 watchdog，63个单线程 worker各占1核。GPU为0，不停止其他任务。
- 启动前重查 CPU 负载，按实际可用物理核执行半机上限；同一主机的本轮调度用文件锁防止重复占用。不能把 SMT 线程当额外物理核。
- 全部源码、规则数据、计划、分割与 Git HEAD 固定在新输出目录；控制器/worker从该副本运行，后续工作区编辑不影响任务。正式运行前提交小版本；生成结果不入 Git。
- 每局独立进程和有限 watchdog，控制器每15秒心跳/更新报告；外层独立 watchdog按绝对截止时间清理本任务进程树。即使控制器被卡住，也不能无限占资源。对局中每约10秒保存模拟进度，真实动作间约1秒持久化一次。
- 记录真实 solver秒、整局墙钟、进程CPU秒、模拟步及整段资源预留核秒。进程被强制结束时最后心跳计数只是下界；整体核时上界包含空闲预留、启动、失败、报告和清理。校准根目录与测试日志另外保留，不能只报成功对局成本。
- 固定CPU与单线程约束有利于可重复性，但共享主机竞争仍可能影响墙钟；这不是独占硬件或硬实时保证。

训练用校准（`outputs/v122/calibration_20261019_a`）共2局×4设置，8/8自然完成；1×短搜索约13秒/局，1×终局约43–47秒/局，4×终局约162–196秒/局。4×的两局得分均低于1×，说明不能预设随预算单调提升；这些是训练种子上的校准，不用于选择方法或正式结论。

## 判断与下一步

1. 高预算稳定涨分：先量化老师上限与CPU成本，再谈模仿学习、学生状态补标及短搜索；不直接启动这些新训练。
2. 短搜索平而终局 rollout 有提升：优先视野/叶估值，不能把采样不足当唯一原因。
3. 两者均平或退步：检查有限候选和启发式后续造成的系统性偏差。模拟同一个弱策略更精确，也可能选择仍然不好的动作。
4. 搜索种子差异大：先检查估计噪声；环境局差异大则检查局面分布依赖。二者分别报告。
5. 任何未完整覆盖的面板都不作为选胜者的依据；不宣称最优、人类上限或3秒部署改进。
