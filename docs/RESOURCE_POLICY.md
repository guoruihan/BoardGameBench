- **a218：GPU + CPU 混合任务**，包括使用 GPU 的策略训练及其采样、评估配套工作。启动前检查节点可访问性、空闲资源和实际 CUDA 运算，不能仅凭显卡可见就认定可用。

- **所有 a 开头的机器：每台最多128个 CPU 核**。这是本项目在该节点上所有并行任务的合计上限，不是每个实验各128核；采样、训练、评估、控制进程均计入，实际分配还受可用资源限制。这不构成对其他 a 节点的自动使用授权。
- **GPU并行粒度**：优先多个独立实验分卡运行，不把本项目的小模型做八卡DDP。用户允许一张卡并发多个独立任务；是否合并按真实显存、吞吐及CPU余量决定，不能只看显卡数量。最新指示是优先使用a218前两张卡（GPU0/1），不因旧的八卡授权自动占用其余六卡。
