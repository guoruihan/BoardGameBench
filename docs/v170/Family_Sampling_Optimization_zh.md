# V1.7.0 / 0.6.3：全部环境的等价采样优化

先在 Harmonies 上验证位集合/C++ 热点，再按用户要求对全部 16 个已验收环境逐个剖析和配对测试。
用户已授权验证后自动恢复原 A/B 试跑；保留原输出目录、模型与剩余预算，不重新发放一小时。

## 修改范围

- 公共复制路径：游戏内部的内建容器数据通过进程内生成、立即消费的 pickle protocol 5 字节复制。保留 tuple、set、整数键、别名、完整历史和 RNG 快照；不加载外部 pickle，也不删除观察或训练数据。
- 合法动作：先用字典比较筛出匹配候选，再保留原 JSON 严格类型检查；特殊 JSON 等价输入走原守卫。非法动作、异常回滚与信息边界不变。
- Cascadia：同一公开观察内复用候选特征的原棋盘地形分、动物放置价值与最佳动物位置；不跨可变局面缓存。
- Harmonies：复用原游戏转移和随机源，用紧凑位集合计算等价地形分与图案可达性；可显式构建 C++ 公共特征内核。避免不需要拿牌时仍计算市场全部动物图案，减少快照与观察的重复构造。
- 原生库：固定源码、静态表、二进制 SHA256，关闭 fast-math；通过配置传入 learner 和所有采样/评测 worker。没有改成另一套 RL 算法。

## 复现与恢复

构建可选原生内核（路径必须是新目录）：

```bash
.venv-train/bin/python -m boardbench.families.harmonies_kernel --build "$NEW_NATIVE_DIR"
```

恢复 Harmonies 时把 `artifact.json` 显式固定进新配置；其他游戏不传此参数：

```bash
.venv-train/bin/python -m boardbench.families.pool_resume \
  --pause-record "$PAUSE_RECORD" --game harmonies --arm B \
  --output "$NEW_OUTPUT" --source-commit "$SOURCE_COMMIT" \
  --harmonies-kernel "$NEW_NATIVE_DIR/artifact.json"
```

该命令只准备新输出目录，并从准备时开始计算原剩余时间；应紧接已授权的资源检查和启动使用。
通用测速入口 `boardbench.families.sampling_benchmark` 接收固定 `--jobs` 清单、独立 `--output` 与 `--kernel`。
`reference` 用于冻结 0.6.2，`python` 使用优化后的 Python 路径，原生路径传 artifact.json。

恢复后的资源观察通过 `boardbench.families.pool_resources` 每 15 秒采样、每 5 分钟汇总，并在任务结束后退出。
区分各任务 CPU/显存与物理 GPU 的共享利用率；恢复阶段吞吐扣除父运行已有动作数及成本。
这些是实际使用量，不是经过并发/CPU 数量扫描验证的最低配额。
